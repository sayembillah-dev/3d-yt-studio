# 3D Youtube Studio

This folder is a video production studio. The user is a YouTuber. When they ask for a video in any wording
("create a video", "make a short about …", "new video", "continue the video", or timestamped feedback like
"at 0:12 …"), **invoke the `stickworld-video` skill and follow it phase by phase.** Do not improvise a different workflow.

## Layout
```
3D Youtube Studio/
  CLAUDE.md                          this file
  ledger.md                          COST LEDGER: one row per video, every production metric (generated by ledger.py)
  .claude/skills/stickworld-video/   the workflow (state machine: topic → research → format → script → voice →
                                     shot plan → gate → build → QA → audio → thumbnail → deliver)
  Engine/                            everything that makes videos (never put project files here)
    studio/                          Remotion + three.js engine (src/engine/*), node_modules
    scripts/                         numeric QA + pipeline tools (python3 / node / bash)
    references/                      style bible, QA rubric, fix playbook, reference measurements, reference videos
    templates/project/               skeleton copied for every new project
    examples/                        00_gate (canonical test shot), demo-pirate-slice
    models/                          whisper model for word timings
  Projects/                          one folder per video: Projects/NN_slug/
    NN_slug/output/                  final.mp4, thumbnail.png, metadata.md  ← what the user picks up
    NN_slug/{project.json, research.md, script.md, shotlist.json, public/, scenes/, work/}
```

## Rules
- Run every command from this folder, quote every path (the folder name has spaces). Never use `npx` (exFAT disk).
- First time on a machine, or if anything fails to start: `bash Engine/scripts/doctor.sh`.
- `Projects/<slug>/project.json` field `phase` is the source of truth for where a video is; resume from it.
- Numbers decide: never call a phase done without pasting its gate output.
- Never spend paid credits, clone a real voice, or use unlicensed music without the user's explicit yes.
- **Cost ledger for every video (user rule):** `ledger.md` keeps one row per video with every metric of producing it —
  tokens (input, cache write/read, output), model(s), API/tool calls, web searches, wall + Claude-active time, sessions,
  renders, fix loops, video length, API-equivalent cost, paid extras, total and cost per video-minute — so we can
  estimate costs. Start every new video with `python3 Engine/scripts/ledger.py begin`; change phases ONLY via
  `python3 Engine/scripts/new_project.py --set-phase <project> <phase>` (it books the ledger); book every approved paid
  credit with `ledger.py extra <project> <usd> "<what>"`; never edit ledger.md by hand. Prices: `Engine/references/pricing.json`.
- Engine changes (new props, sets, character features) go in `Engine/studio/src/engine/` and must keep
  `Engine/examples/00_gate` rendering (re-run its gate after engine edits).
